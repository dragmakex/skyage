# Project commands

Use Bun for dependency management and JavaScript tooling: `bun install`, `bun run <script>`, and `bunx <tool>`. Do not use npm, npx, Yarn, or pnpm.

Run the existing Jest suite with `bun run test --runInBand`, not `bun test`. Type-check with `bun run typecheck`. Commit `bun.lock` when dependencies change.
